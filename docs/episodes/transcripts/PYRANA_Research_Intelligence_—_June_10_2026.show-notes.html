Papers covered:

  • AGORA: Adapter-Grounded Observation-Action Retention for Inference-Free Prompt Compression in LLM Agents — Step-level trajectory compressor runs in ~2ms with no LLM calls; token-level compression collapses agent task completion to near zero.
  • MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation — Agents autonomously create, store, and evaluate reusable skills, improving performance on novel tasks over time.
  • MemFail: Stress-Testing Failure Modes of LLM Memory Systems — Diagnostic methodology that systematically surfaces where LLM memory systems break under adversarial and edge-case conditions.
