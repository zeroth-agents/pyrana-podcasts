Four papers, one vertical stack. This episode traces a path from application benchmarking through agent self-modification and tool surface design down to multi-agent security — each paper landing at a different layer of the same architecture. Listeners come away with a clear map of where the frontier is moving simultaneously across evaluation, self-improvement, API unification, and governed communication.

For PYRANA and Cortex, the stakes are concrete: WorkstreamBench hands us both a scoring threat and a ready-made CxU schema for financial agent output. MOSS is the reference architecture for any future self-patching harness work. HarnessAPI closes a real gap where PYRANA tools are agent-reachable but not HTTP-reachable. And LCGuard surfaces a governance blind spot — KV cache sharing — that needs to be documented before any cache-efficiency work ships.

Papers covered:

  • WorkstreamBench: Evaluating LLM Agents on End-to-End Spreadsheet Tasks in Finance — First transparent benchmark for complex financial spreadsheet construction; even top agents fall short of professional standards.
  • MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems — Agent rewrites its own harness-level source code from failure logs, lifting task scores from 0.25 to 0.61 in one cycle.
  • HarnessAPI: A Skill-First Framework for Unified Streaming APIs and MCP Tools — Single skill definition that exposes tools to both AI agents and standard HTTP clients simultaneously.
  • LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems — Detects covert information leakage through shared KV caches in multi-agent deployments.

Takeaways for our platform:

  • Run pyrana-demo-2 against WorkstreamBench this sprint and publish internal scores; also adopt the Accuracy/Formula/Format taxonomy directly as a CxU sub-claim schema for financial agent artifacts, mapping each dimension to a verifiable pass/fail verdict with supporting evidence.
  • Use MOSS as the reference architecture for the self-patching harness design — specifically its seven-stage pipeline with an external coding agent and sandboxed rollback — whenever that work enters the sprint queue.
  • Before shipping any KV cache efficiency feature, document the LCGuard threat model in the Cortex governance layer and specify what the audit trail can and cannot observe about inter-agent latent communication.
