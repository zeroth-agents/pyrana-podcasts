Papers covered:

  • DRFLOW: A Deep Research Benchmark for Personalized Workflow Prediction — benchmarks AI agents on producing ordered, user-specific procedural plans from 3,900-plus enterprise sources across seven quality dimensions.
  • All Smoke, No Alarm: Oracle Signals in Agent-Authored Test Code — finds that 80% of test patches written by coding agents contain no meaningful assertion, making pass/fail results unreliable as a verification signal.
  • RubricsTree: Scalable and Evolving Open-Ended Evaluation of Personal Health Agents across Health Memory and Medical Skills — introduces a hierarchical, updatable rubric structure for evaluating agents in regulated, high-stakes domains.
  • The Stanford EDGAR Filings Dataset — reconstructs SEC filings into layout-faithful, token-efficient pretraining data optimized for financial document ingestion.
